# Definitely Fitness

Plataforma fitness integral para iOS y Android: entrenamiento, nutrición, progreso, gamificación y comunidad.

**Estado:** fase documental. Todavía no hay código de la aplicación.

- Documentación del producto: carpeta `docs/`.
- Línea base documental aprobada: v0.2.2. Las versiones posteriores son propuestas en la rama de trabajo.
- El nombre "Definitely Fitness" es el nombre comercial aprobado, sujeto a validación legal y de marca (DEC-53).
